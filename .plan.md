# Spline 3D Integration Plan — WardrobeAI

## Overview
Integrate `@splinetool/react-spline` (already installed) into three locations across the app,
matching the dark gold (#C8A97E on #0C0C0C) fashion theme.

The **Navbar** option is dropped — the bar is 64px tall, too small for a 3D scene, and a
persistent scene would drain mobile battery/GPU.

---

## Scene URLs

All three placements use the **same known public Spline blob/orb scene** from the official
`react-spline` README. The orb is a golden-tinted, softly lit abstract shape — a perfect fit
for the app's luxury palette. Each placement can later be swapped for a different template URL.

```js
// frontend/src/lib/scenes.js  (new constants file)
export const SCENES = {
  splash:       'https://prod.spline.design/6Wq1Q7YGyM-iab9i/scene.splinecode',
  wardrobeHero: 'https://prod.spline.design/6Wq1Q7YGyM-iab9i/scene.splinecode',
  addItemIdle:  'https://prod.spline.design/6Wq1Q7YGyM-iab9i/scene.splinecode',
}
```

The user can open any URL in Spline editor → Export → React → copy new URL and drop it in.

## Step 2 — `frontend/src/components/SplineScene.jsx`

Lazy-loads `@splinetool/react-spline` via `React.lazy` so it never blocks the initial bundle.
Wraps in an error boundary so a failed/offline scene load silently hides the element rather
than crashing the page.

```jsx
import { Suspense, lazy, Component } from 'react'

const Spline = lazy(() => import('@splinetool/react-spline'))

class SplineErrorBoundary extends Component {
  state = { failed: false }
  static getDerivedStateFromError() { return { failed: true } }
  render() { return this.state.failed ? null : this.props.children }
}

export default function SplineScene({ scene, style, className }) {
  // Respect prefers-reduced-motion — hide 3D for users who opt out
  if (window.matchMedia('(prefers-reduced-motion: reduce)').matches) return null

  return (
    <SplineErrorBoundary>
      <Suspense fallback={null}>
        <Spline scene={scene} style={style} className={className} />
      </Suspense>
    </SplineErrorBoundary>
  )
}
```

Props:
- `scene` — URL string from SCENES constant
- `style` / `className` — passed straight through to Spline

## Step 3 — `frontend/src/components/SplashScreen.jsx`

Shown only on **first app launch** (checked via `sessionStorage`). Auto-dismisses after 2 s
or immediately on tap. Framer Motion `AnimatePresence` handles the fade-out.

Layout:
```
┌─────────────────────────────────────┐
│                                     │
│                                     │
│         [Spline orb — full]         │
│                                     │
│        WARDROBE AI        (text)    │
│    Your personal stylist  (sub)     │
│                                     │
│                                     │
└─────────────────────────────────────┘
```

- Background: `var(--bg-primary)` (#0C0C0C)
- Spline scene fills 100% of the splash div, `pointer-events: none`
- Text overlaid at bottom-centre, gold accent colour
- `z-index: 9999` to sit above everything
- On dismiss → `sessionStorage.setItem('splashSeen', '1')` so it doesn't re-show on tab switch

## Step 4 — `frontend/src/App.jsx`

Mount `<SplashScreen>` above `<AnimatePresence>`. The splash renders in its own layer:

```jsx
const [showSplash, setShowSplash] = useState(
  () => !sessionStorage.getItem('splashSeen')
)

return (
  <div …>
    <AnimatePresence>
      {showSplash && <SplashScreen onDone={() => setShowSplash(false)} />}
    </AnimatePresence>
    <AnimatePresence mode="wait" initial={false}>
      <Routes …>…</Routes>
    </AnimatePresence>
    <Navbar />
  </div>
)
```

## Step 5 — `frontend/src/pages/Wardrobe.jsx`

Replace the plain text hero block with a **3D hero section**: Spline scene fills a 180px
container, title text sits on top via absolute positioning.

```
┌────────────────────────────────────────┐  ← 180px hero
│  [Spline orb — pointer-events: none]  │
│  Personal                (text over)  │
│  My Wardrobe             (text over)  │
│  42 items                (text over)  │
└────────────────────────────────────────┘
  [filter pills]
  [grid]
```

- Spline `opacity: 0.85`, `mix-blend-mode: lighten` for subtle blending with dark bg
- No interactivity (pointer-events: none) so filters/grid still work normally
- Falls back gracefully to plain text header if Spline fails to load (the text is always there)

## Step 6 — `frontend/src/pages/AddItem.jsx` (idle phase only)

On the `idle` phase, show a **200px 3D scene** between the header and the action buttons.
It replaces empty vertical space and sets a premium mood before the user picks a capture method.

```
┌──────────────────────┐
│ Add to Wardrobe      │  ← header
│ New Item             │
├──────────────────────┤
│  [Spline scene 200px]│  ← new
├──────────────────────┤
│  [Take Photo btn]    │
│  [Upload btn]        │
│  [Scan Barcode btn]  │
└──────────────────────┘
```

- Wrapped in `motion.div` with `opacity: 0 → 1` (0.6s fade-in) so it appears smoothly
- `pointer-events: none` — doesn't block the buttons below
- Hidden when in any other phase (camera, previewing, uploading, etc.)

---

## Performance Notes

- `React.lazy` splits Spline out of the main bundle — no cost if scene never renders
- Single `@splinetool/react-spline` package shared across all three placements
- Spline scenes are cached by browser after first download
- Splash dismisses before user interacts, so wardrobe/add scenes load in background
- If Spline CDN unreachable: error boundary returns `null`, app works normally
